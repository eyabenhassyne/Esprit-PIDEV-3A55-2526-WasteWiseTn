# WasteWise TN 🌿

WasteWise TN est une **plateforme citoyenne** développée avec **Symfony** permettant aux utilisateurs de déclarer leurs déchets, de suivre leurs déclarations et de contribuer à une Tunisie plus propre grâce à un système d'EcoPoints.

---

## 🎯 Objectifs du projet
- Sensibiliser les citoyens à la gestion des déchets
- Faciliter la déclaration des déchets recyclables
- Centraliser les déclarations dans un tableau de bord
- Encourager les bonnes pratiques écologiques

---

## 🛠️ Technologies utilisées
- **Backend** : Symfony (PHP)
- **Frontend** : Twig, HTML, CSS
- **ORM** : Doctrine
- **Base de données** : MySQL
- **Outils** : Git, GitHub
